# Lunar Regolith Simulant Database

A browsable database of lunar regolith simulants: the materials used on Earth to stand in for Moon soil in research and testing. For each simulant it lists its composition, chemical composition, production site and references, with a map of where simulants are made.

Live page: https://soutone.github.io/lrs-dashboard/

Plain HTML, CSS and JavaScript; the data is in `data/`.
